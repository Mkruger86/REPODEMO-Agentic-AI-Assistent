Jeg har lavet opsætning med requirements.txt. Alt i skal gøre ved kloning af repoet:

1: Klon repoet til en lokal folder på jeres harddrive. Undgå onedrive
2: åben en terminal i VS code.
3: Skriv python -m venv .venv i terminalen
4: Skriv derefter .\.venv\Scripts\python.exe -m pip install -r requirements.txt

Miljøet er klart
